
# 🌍 GeoClock

**GeoClock** is a simple Python-based application that fetches the **current local time and date** for any location in the world using geolocation and timezone libraries.

---

## 🛠️ Features
- Takes user input for a location (city, country, etc.)
- Converts the location into geographic coordinates using `geopy`
- Identifies the correct timezone using `timezonefinder`
- Displays the current local time and date using `pytz` and `datetime`
  ## 🚀 Technologies Used
- Python 3.x
- [Geopy](https://pypi.org/project/geopy/)
- [TimezoneFinder](https://pypi.org/project/timezonefinder/)
- [pytz](https://pypi.org/project/pytz/)
